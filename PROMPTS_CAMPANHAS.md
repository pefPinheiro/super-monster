# Guia de Prompts das Campanhas — Google Flow (Nano Banana 2.1)

Este guia contém os prompts prontos para gerar os **5 cenários (backgrounds) das Campanhas de Guerra** e os **4 ícones de nós/fases do mapa** no **Google Flow (`Nano Banana 2.1`)**.

## Configuração no Flow
- **Aba:** `Imagem`
- **Modelo:** `Nano Banana 2.1`
- **Diretório de destino:** `D:\Bcode\Super Monster\Assets\Campanha\`
- **Referência de estilo (opcional):** `Assets/referencia_estilo_master.png`
