# Prompts de Imagens — Tela Profissional de Decks (Super Monster)

Todos os arquivos abaixo são opcionais (a UI já funciona com acabamento CSS estilizado), mas ao adicioná-los na pasta `Assets/UI/` com os nomes exatos abaixo, o jogo os carrega automaticamente!

## 1. Fundo da Tela de Decks (`bg_deck_armory.png`)
- **Caminho:** `Assets/UI/bg_deck_armory.png`
- **Proporção recomendada:** `9:16` (vertical, ex.: `1080x1920`)
- **Uso:** Fundo atmosférico do Arsenal / Grimório de Decks.
- **Prompt (EN):**
  > Dark fantasy runic card armory and ancient arcane library interior, obsidian stone pillars with subtle glowing golden and cyan runes, warm candlelight and floating dust motes, deep moody shadows in the center for UI readability, rich painterly digital illustration, Hearthstone and Marvel Snap dark fantasy UI backdrop style, no characters, no text, no cards, vertical 9:16 composition.
